## Sobre o Projeto
Este repositório/documento apresenta um exemplo prático da aplicação de Estruturas de Dados em situações do mundo real. O problema selecionado foi a implementação do histórico de navegação de um navegador web, utilizando o conceito de **Pilha (Stack / LIFO - Last-In, First-Out)**.

## Conteúdo
O material inclui:
1. Explicação teórica sobre o funcionamento da estrutura de dados do tipo Pilha.
2. Demonstração de como as operações `PUSH` (adicionar/visitar página) e `POP` (remover/voltar página) resolvem o problema do histórico.
3. Exemplo de implementação básica em linguagem Python.
